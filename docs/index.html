这是什么

BorderPulse 是基于香港政府开放数据的口岸错峰过关助手：预测 8 个陆路 / 跨界口岸未来 14 天的拥挤度，告诉你要不要换日子、换口岸、换方向、几点出发，并把「排队超过 30 分钟」的概率量化出来。

方法流水线（全部自写实现）

ImmD 日客流 → LOF 异常清洗 → GBT 预测（直方图梯度提升树，递归 14 天）→ 马尔可夫 4 档拥挤状态 → 蒙特卡洛排队模拟（Erlang-C）→ 推荐（哪天 / 哪个口岸 / 哪个方向 / 几点）
旁路：TF-IDF + 逻辑回归情感分析 → 错峰景点推荐

当前为 v0.3 版：主模型为自写 NumPy 梯度提升树（LOF 清洗后训练，滚动回测 RMSE 比星期中位数基线低约 31%，亦优于 sklearn 基准）；逐小时曲线为口岸类型模板 × Erlang-C； 弹层附马尔可夫状态概率与最近一天实测。评分标准详情见课程报告。

数据来源

  • 入境处 · 每日各管制站旅客人次（核心时序，2021-01 至今）
  • 海关 · 管制站旅客吞吐量（年度容量锚）
  • TripAdvisor 景点评论（情感模型训练，HuggingFace 镜像）

声明

预测仅基于历史统计规律，不构成出行保证；口岸临时管制、天气及突发事件不在模型内。 景点页的香港评论为演示用合成语料（已在报告中标注；情感模型本身仅用真实评论训练）。 MATH7005 课程项目数据产品。
